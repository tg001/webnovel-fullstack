# Webnovel Fullstack - 网文小说全链路辅助创作 Skill

> 一个覆盖网文创作全流程的 AI Agent Skill，从创意到完本到商业化的全方位辅助。

## 简介

`webnovel-fullstack` 是一个为网文小说创作者设计的全链路辅助创作 Skill。它整合了拆书借鉴、世界观构建、人物设计、剧情规划、文风打磨、去AI味、专项技法、正文写作、审核质检、平台运营等十大模块，支持男频女频各品类，帮助创作者从创意阶段一路走到完本和商业化。

**版本**：v1.7
**文档规模**：16份参考文档 + 1份总索引，约4800行
**核心特色**：基于283万字语料统计的实证去AI味方法论、7位名家文风速查、网文工业化创作流程

## 核心亮点

### 1. 基于实证的去AI味方法论

整合开源项目 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone) 的283万字语料统计研究：

- **11项经统计验证的AI特征**：拟人化喻体（R=7.3）、段首零回指评论（R=4.4）、对举结构（R=3.4）等
- **15项流行但错误的认知修正**：人类用比喻是AI的2.4倍、句长均匀度无差异、人类设问是AI的17倍
- **模型间差异可达40倍**：不存在统一的"AI文风"，去味需根据实际模型调整

### 3. 网文工业化创作流程

- **7步SOP**：核心定位→世界观人设→大纲→细纲→正文→审核→运营
- **三层骨架+三张表**：解决AI长篇记忆崩塌问题
- **四轮去味流水线**：去痕→节奏→人味→通读
- **项目脚手架**：目录结构+维护文档+读写纪律，支持百万字长篇

### 4. 全品类覆盖

- **男频**：玄幻修仙、都市异能、历史穿越、系统流、反套路修仙/黑色幽默
- **女频**：甜宠、虐文、宫斗宅斗、种田、穿书重生
- **番茄特色**：脑洞文、衍生文、癫文、系统爽文、官场职场

## 安装使用

### 方式一：作为 Skill 安装

将本仓库克隆或复制到你的 Skill 目录：

```bash
# 豆包工作/办公模式
cp -r webnovel-fullstack /path/to/.user_skills/

# 或使用 npx（如支持）
npx skills add tg001/webnovel-fullstack
```

### 方式二：作为 System Prompt 使用

直接将 `SKILL.md` 和 `references/` 目录作为上下文提供给支持自定义指令的 AI 工具。

### 方式三：单独使用参考文档

`references/` 目录下的每份文档都是独立的方法论，可以单独阅读和使用。

## 快速开始

1. **从零开始**：阅读 `08-quickstart-templates.md` 的7步SOP，按流程推进
2. **遇到问题**：查阅 `08-quickstart-templates.md` 的"24种常见问题诊断表"
3. **写正文前**：用 `06a-story-foundations.md` 的故事感十二支柱对照检查
4. **写完后**：用 `06b-ai-diagnosis.md` 的五轮诊断+55条禁令自检
5. **去AI味**：遵循"白名单原则+信息守恒+语义判断排除"三原则
