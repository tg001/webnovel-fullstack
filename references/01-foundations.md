# 创作基础：拆书、借鉴、大纲与细纲

> "地基"阶段：拆书分析、合规借鉴、全书大纲、章节细纲、按体量适配结构。
> **配套**：动笔前对照 `06a` 十二支柱，成稿后对照 `06b` 诊断清单自检。

## 第一部分：拆书分析

**为什么要拆书**：网文是类型文学，每个品类都有成熟的套路和读者预期；拆爆款为什么爆，比自己摸索快10倍。拆书是"拆解结构、提炼技法、化为己用"，不是抄袭。新手至少拆3本同品类爆款再动笔。

### 一、三层拆书法

**第一层：宏观结构（看森林）**
核心定位（一句话说清卖点）→ 主线结构（几卷，每卷的核心冲突和高潮）→ 节奏曲线（每10章标注情绪峰值）→ 人物关系网。输出：全书结构图。

**第二层：中观技法（看树木）**
开篇分析（前3章用什么钩子、主角怎么出场、核心冲突怎么引入）→ 高潮分析（铺垫几章、什么压抑手法、爆发怎么写）→ 转折分析（怎么设计的、有无伏笔、冲击力来自哪）→ 人物分析（主角弧线、配角塑造、反派动机）。输出：可复用技法清单。

**第三层：微观语言（看树叶）**
句式节奏（长短句搭配）→ 对话风格（潜台词、角色差异）→ 描写技巧（展示而非告知怎么实现）→ 钩子设计（章末钩子类型）。输出：语言风格笔记。

### 二、老王三步拆书法（实战版）

> 拆了30本爆款为什么开篇还是没人看？不是拆书没用，是从一开始就拆错了。核心：**拆书拆的是神不是形，拆完必须重构，不然全白拆。**

**第一步：选书（拆金不拆远，拆准不拆杂）**

| 原则 | 说明 | 反面例子 |
|------|------|---------|
| **同品类** | 写什么品类就拆什么品类的当下爆款 | 写都市重生去拆《诡秘之主》=短跑运动员研究游泳 |
| **当下火** | 拆现在正火的，别拆过时老书 | 拆10年前的神作，市场口味早就换了 |
| **新人优先** | 新人最该拆刚火起来的新人作者 | 一上来就拆大神神作，你看不懂里面的"成神密码" |
| **有成绩再拆神** | 等有了成绩或遇瓶颈再拆大神 | 笔法不到位，拆神作只能学到形学不到神 |

**为什么拆新人作者**：第一本书他们笔法未必完美，但市场嗅觉极准，成功路径也最容易复制。市场已经用点击/追读/月票替你筛出了答案，那些才是命门。

**第二步：动刀（四个维度解剖一本爆款）**

**维度1：拆骨架（大纲与节奏）**
- 准备表格或白纸，每看一章用一句话概括这章发生了什么
- 重点看前三章：主角怎么入场？目标是什么？金手指怎么给？悬念和期待感怎么埋？
- 看起承转合：这章是铺背景还是拉仇恨？是过渡还是爆发？
- 看高潮分布：多少章一个小高潮？多少章解决一个大危机？
- **规律**：爆款书的节奏惊人相似——十章左右一个小高潮，五十章左右换地图，这就是网文工业模板

**维度2：拆人设（别让角色像相片）**
- 主角看三点：最鲜明的标签是什么？（腹黑/狠辣/谨慎/疯批）核心诉求是什么？（为什么非要变强/有钱/掌权）性格缺陷是什么？
- 看互动关系：配角怎么捧主角？反派怎么立起来？
- **核心**：好的人设不是形容词堆出来的，是在关系里撞出来的

**维度3：拆情绪（网文卖的就是情绪价值）**
- 边看边标：哪里爽？哪里憋屈？哪里想弃书？哪里又忍不住点下一章？
- 看作者怎么压读者：困难堆得越高，反弹才越爽
- 这个压抑过程持续了多少次？章末又留了什么钩子？
- **钩子分类**：利益钩（能得到什么）、信息差钩（读者知道角色不知道）、情感钩（人物关系变化）
- 学会识别钩子，你才会留人

**维度4：拆比例（对话/场景/金句）**
- 对话：高手写对话几乎没废话，每句都在推剧情或露性格
- 打斗：为什么热血？用了哪些动词？怎么用周围人的反应侧面烘托？
- 金句：摘下来不是抄，是学语感和逻辑
- **基本功往往就藏在这些比例里**

**第三步：重构（拆完必须重构，不然全白拆）**

> 只拆不重构=看了30本健身教程还是不会练。拆完必须动手，这才是进步最快的时候。

**问自己三个问题**：
1. 如果我是作者，这个转折我会怎么写？我写的有他好吗？
2. 如果把这个金手指换掉，逻辑还通不通？
3. 这段里哪句对白、哪个细节是我绝对想不出来的？

**重写对比法**：
- 找最精彩的一段，按你总结的骨架，**不看原文**，用自己的话重写
- 写完再对比原文，你会痛苦地发现：
  - 我200字才讲清的事，人家三句话就完了
  - 我忘了埋伏笔，所以后面反转特别突兀
  - 我的对话全是废话，人家每句都在推剧情
- **别怕挫败，这种对比就是你进步最快的时候**

**拆书金句**：拆书拆的是神不是形。写小说没有捷径，但拆书是离成神最近的那条路。

### 三、拆书报告模板

```
书名：　作者：　平台/品类：　字数/状态：

一、核心定位：一句话概括 / 核心卖点 / 目标读者 / 爽点类型
二、宏观结构：卷级划分（每卷冲突+高潮+结局）/ 主线类型 / 节奏曲线（高潮点章节位置）
三、中观技法：开篇钩子 / 高潮设计 / 转折反转 / 人物塑造 / 伏笔设计
四、微观语言：句式特点 / 对话风格 / 描写技巧 / 章末钩子
五、可复用技法清单（最重要，5-8条，写成"以后我可以这样写：……"）
六、不足与可优化点
```

## 第二部分：合规借鉴

### 一、借鉴的三个层次

1. **结构借鉴（安全，推荐）**：三幕式、英雄之旅、升级流节奏、开篇黄金三章、章末钩子等行业通用方法论——不算抄袭。
2. **元素借鉴（需改造，谨慎）**：金手指类型、世界观设定、人物关系模式等具体元素——必须过"三换原则"改造。
3. **情节借鉴（高风险，不推荐）**：具体情节走向、事件序列、关键转折——即使改名换细节也可能被认定洗稿，新手不要碰。

### 二、三换原则（元素借鉴的安全线）

借鉴任何具体元素必须同时满足：
1. **换背景**：放到完全不同的世界观/时代/场景（修仙宗门斗争→都市公司竞争）。
2. **换人物**：身份、性格、关系完全不同（高冷师尊×叛逆徒弟→毒舌上司×佛系下属）。
3. **换细节**：具体事件、对话、描写全部重写，只保留核心逻辑（保留"被误解后用实力证明自己"，但事件/对手/方式全不同）。

**判断标准**：普通读者能不能看出"这是从XX借鉴来的"？能看出=改造不够；看不出=安全。

### 三、原创度自检

- [ ] 核心设定（金手指/世界观/力量体系）是原创的吗？
- [ ] 主要人物的性格、背景、关系是原创的吗？
- [ ] 主线走向、关键转折和高潮是原创的吗？
- [ ] 对话和描写是自己写的吗（无大段复制）？

**红线（绝对不做）**：大段复制原文（即使改几个词）；照搬核心设定；照搬人物关系；照搬情节序列。

## 第三部分：全书大纲

### 一、核心定位五问

1. **主角是谁？**（身份/性格/核心欲望/核心恐惧）——不写"废柴逆袭"，写具体的人："被家族抛弃的庶子，想证明自己比嫡子强，最怕被人看不起"。
2. **这是个什么样的世界？**（核心规则/核心矛盾/和主角的关系）——不写"修仙世界"，写核心规则："靠灵根决定命运的世界，没有灵根连修仙资格都没有"。
3. **主角想要什么？** 短期目标具体可操作（"三个月内通过入门考试"）；长期目标关联核心欲望；真正想要的是情感层面（被认可/被爱/赎罪）。
4. **谁/什么在阻止他？** 最好多层冲突：外部（反派）+ 内部（自身缺陷）+ 环境（世界规则）。
5. **读者为什么要追这本书？**（核心爽点/卖点/差异化）用一句话说清："这是一本关于___的书，最___的地方是___"。

### 二、三幕式全书结构

**第一幕：建立期（10-20%）**：主角初始状态（困境/缺陷/欲望）→ 核心冲突引入 → 第一个小高潮（证明自己能成事）→ 结尾：进入更大舞台（离开新手村）。

**第二幕：成长期（20-80%）**：
- 上半段（20-50%）：逐步变强、扩展范围，遇到更多对手和盟友；**中点反转**——故事进行到一半出现改变走向的大反转（真相揭露/盟友背叛/目标改变）。
- 下半段（50-80%）：冲突升级、更大挑战和牺牲；**最低点**——最大失败/失去，陷入绝境；**触底反弹**——从绝境站起来，获得新力量/觉悟。

**第三幕：收束期（80-100%）**：线索汇合 → 终极决战 → 主线闭环、人物归宿、世界新格局 → 余韵（情感落点，不戛然而止）。

### 三、卷级大纲表

```
第X卷：[卷名]　字数范围：第___章 - 第___章（约___万字）
核心冲突：（本卷主要矛盾）
主角目标：（本卷想达成什么）
关键事件：（按时间顺序3-5个）
高潮点：（最大高潮在第几章，什么事件）
转折点：（有没有改变走向的转折）
结局状态：（卷末主角/局势的状态）
伏笔埋设：（埋哪些伏笔，计划在哪卷回收）
人物变化：（主要人物本卷的成长/变化）
```

### 四、大纲自检

- [ ] 五问都答了？能一句话说清这本书讲什么？
- [ ] 主角核心欲望具体可操作？（不是"变强"）
- [ ] 核心冲突清晰且多层？（外部+内部+环境）
- [ ] 三幕完整？有中点反转、最低点、触底反弹？
- [ ] 每卷有核心冲突和高潮？每10章主线有推进？
- [ ] 爽点/卖点明确？和同品类有差异化？

## 第四部分：章节细纲

### 一、单章细纲模板

```
第X章：[章节名]　字数：约2000-3000字　视角人物：
本章功能：（推进主线/塑造人物/释放信息/营造氛围/过渡衔接）
核心冲突：

场景列表：1. [场景名]-[地点]-[参与人物]-[发生了什么]　2. ...

关键情节：
- 开头钩子：（第一句/段怎么抓住读者）
- 发展：（情节怎么推进）
- 小高潮/转折点：
- 章末钩子：（怎么让读者点下一章）

人物状态：主角（情绪/目标/变化）+ 其他关键人物（做了什么，状态如何）

信息释放：本章释放的新信息（设定/伏笔/背景）+ 新埋伏笔及计划回收章

情绪曲线：开头基调 → 发展变化 → 高潮峰值 → 结尾落点+钩子
```

### 二、五种章节功能类型

| 类型 | 功能 | 节奏 | 必须有 | 避免 |
|------|------|------|--------|------|
| 推进型 | 推进主线，改变局势 | 快，冲突密集 | 改变局势的事件+章末钩子 | 大段描写心理活动 |
| 塑造型 | 深入塑造人物 | 中等，有情感浓度 | 展现性格的关键事件/对话+情感变化 | 纯旁白介绍人物 |
| 信息型 | 释放设定/伏笔/背景 | 中等，有悬念 | 信息通过经历/对话/发现自然释放 | 大段设定灌输（读者会跳）|
| 氛围型 | 营造情绪氛围 | 慢，重感官 | 强氛围+五感细节 | 纯环境描写无互动 |
| 过渡型 | 连接两个事件 | 快，信息量高 | 简洁过渡+下个事件引子 | 拖沓（1章足够，不拖成2-3章）|

### 三、章末钩子八种类型

1. **悬念型**："他推开门，看到了一个绝对不该出现在这里的人。"
2. **危机型**："就在这时，警报响了——敌人来了。"
3. **反转型**："他笑了。'你以为你赢了？'"
4. **揭秘型**："那封信的最后一行，让他的血液瞬间凝固。"
5. **选择型**："现在，他必须在三分钟内做出选择。"
6. **情绪型**："她转过身，眼泪终于流了下来。"
7. **伏笔型**："他没有注意到，角落里那双眼睛，一直盯着他。"
8. **爽点型**："'接下来，该轮到我了。'他活动了一下手指。"

### 四、细纲自检

- [ ] 本章功能明确？核心冲突清晰？
- [ ] 开头有钩子（前300字抓住读者）？
- [ ] 有小高潮或转折（不平铺直叙）？
- [ ] 章末有钩子（想点下一章）？
- [ ] 视角锁定（一章内不跳）？
- [ ] 信息释放自然（无大段设定说明）？
- [ ] 节奏匹配功能？和前后章衔接自然？

### 五、硬性门禁：缺细纲不许写正文

> **这是防止写崩的第一铁律。** 没有细纲就写正文=闭着眼睛开车，必然跑偏、注水、前后矛盾。

**门禁规则：**
1. **每章正文写作前，必须有本章细纲**（至少包含：本章功能、核心冲突、开头钩子、关键情节、章末钩子）
2. **细纲未通过自检，不许写正文**——用上面的"细纲自检"清单检查，全部通过才能动笔
3. **写正文时严格遵循细纲**——如果写着写着想偏离，先停下来更新细纲，再继续写
4. **连续3章偏离细纲=大纲有问题**——停下来重新审视卷级大纲，不要硬写

**为什么这么严**：
- AI没有全局规划能力，不给细纲就会"想到哪写到哪"
- 没有细纲的正文，90%会出现：节奏拖沓、冲突平淡、伏笔遗忘、人设崩塌
- 细纲是"导航"，正文是"开车"——没有导航必然迷路
- 写细纲只花10分钟，但能省下几小时的改稿时间

**例外**：灵感爆发时可以先写正文，但写完后必须补细纲，并检查正文是否符合整体大纲。

## 第五部分：按体量适配结构

| 体量 | 字数 | 章节数 | 结构特点 | 核心要求 |
|------|------|--------|---------|---------|
| **短故事** | 1-5万 | 3-8章 | 章章有钩子，结尾留余韵 | 伏笔全回收；人物≤5人；开篇直入冲突不铺垫 |
| **短篇** | 30-50万 | 50-100章 | 1卷或上中下三部；起（1-30%）承（30-70%）合（70-100%） | 中点必有大反转 |
| **长篇** | 100-300万 | 300-800章 | 多卷结构，每卷独立起承转合 | 卷间递进（地图扩大/对手变强/真相揭露）；伏笔跨卷回收但定期提醒 |
| **超长篇** | 300万+ | 800章+ | 多卷+多部，每部独立主题，部间可时间跳跃 | 世界观够大、力量体系有足够升级空间防写崩；每部开始"重启"给新目标新环境 |

**选择建议**：新人首选短篇（容易完本积累经验）；有经验后写长篇（主流体量）；**不要一开始就写超长篇**——90%新人超长篇烂尾。超长篇必须建立维护文档体系（见 `12`）。
