# 世界观与力量体系：世界、技能与战斗的完整设计

> "设定"阶段：世界观七层模型、技能/金手指设计、战斗体系设计。好的设定是故事的土壤，不是展示的橱窗——设定必须服务于剧情和人物。
> **配套**：动笔前对照 `06a` 十二支柱，成稿后对照 `06b` 诊断清单自检。

## 第一部分：世界观设计

### 一、核心原则

1. **世界观是土壤不是橱窗**：为人物和剧情提供舞台，不为"设定宏大"堆砌无关设定。好世界观是冰山——露出水面的是剧情需要的，水下的是作者心里有数的。
2. **规则必须自洽且有代价**：核心规则全书遵守不打补丁；任何超能力都有限制和代价（没有代价的能力毁掉剧情张力）；规则边界清晰（什么能做/不能做/做到什么程度需要什么条件）。
3. **世界观服务于核心冲突**：先想"这个世界的核心矛盾是什么"，主角的困境和追求应与核心规则紧密相关。故事换到另一个世界观也能成立=结合不够深。

### 二、三招快速建世界观（新手捷径）

> 新手写世界观最容易犯的错：堆砌设定但没有运转逻辑，规则存在但没有代价，一次性把所有设定倒给读者。
> 记住三招：**先立规则 → 再加代价 → 分层释放**。

#### 第一招：先立规则——找到世界的"发动机"

**核心思路**：不要从"这个世界有什么"开始，要从"这个世界的核心稀缺资源是什么"开始。稀缺资源是所有人的欲望来源，也是所有冲突的根源。

**五步立规则：**

1. **设定核心稀缺资源**（唯一核心欲望来源）
   - 修仙文：灵气/灵石/功法/长生
   - 末世文：食物/水/安全区/异能晶核
   - 历史文：功名/土地/权力/盐铁
   - 都市文：金钱/信息/人脉/技术
   - 玄幻文：血脉/神格/信仰/世界本源
   - **关键**：这个资源必须是"稀缺"的——不是人人都有，获得它需要付出代价

2. **写明垄断势力和管控规则**
   - 谁控制了这个资源？（宗门/皇室/财阀/教会/异能者协会）
   - 他们用什么规则管控？（配额制/等级制/世袭制/考试制/黑市）
   - 违反规则的后果是什么？（死亡/流放/剥夺资源/社会死亡）

3. **划分社会阶层**
   - 顶层：垄断资源的人（掌握规则制定权）
   - 中层：分配资源的人（掌握规则执行权）
   - 底层：争夺资源的人（只能在规则缝隙中生存）
   - 每个阶层获取资源的门槛和代价是什么？

4. **写出天然对立矛盾**
   - 上层维稳手段：武力镇压/思想控制/分化瓦解/资源诱饵
   - 底层生存困境：被剥削/被欺骗/被利用/没有出路
   - 中层的尴尬：向上爬要付出什么？向下压要承受什么？
   - **这些矛盾就是剧情的矿藏**——主角的故事必然在这些矛盾中展开

5. **重点写运转逻辑，不罗列设定**
   - 错误："这个世界有灵气，分为炼气、筑基、金丹三个等级，宗门有七个..."
   - 正确："灵气稀薄，只有灵脉附近才能修炼。七大宗门垄断了所有灵脉，散修只能在灵气稀薄的荒野挣扎。主角是个散修，他发现了一条被遗忘的灵脉..."
   - **规则必须能衍生出剧情冲突**，不能衍生冲突的规则就是无效设定

**承重规则选择法**：
- 只选3个"承重规则"——这些规则必须真正影响第一幕中的人物行为
- 例子："铁会灼烧魔法使用者""水由公会法律配给""死者会说话七天""女性不能继承土地"
- 如果一个规则不会改变某个人在场景中的行为，它就是"琐事"，琐事放到后面再说
- 每个规则用一句话写清楚，不要写成长篇大论

#### 第二招：再加代价——让规则"咬人"

**核心思路**：规则存在但如果不付出任何代价、不改变任何东西，就是无效设定。好的规则会"咬人"——使用它有代价，违反它有后果，它会改变人物的选择和命运。

**代价的四种类型：**

| 代价类型 | 说明 | 例子 |
|---------|------|------|
| **身体代价** | 使用能力/资源对身体造成的伤害 | 施法消耗寿命、异能使用后虚弱、修炼走火入魔 |
| **社会代价** | 行为对社会关系和地位的影响 | 使用禁术被宗门追杀、暴露异能被研究所抓捕、打破规则被社会排斥 |
| **道德代价** | 选择对良心和价值观的冲击 | 为了力量牺牲无辜者、为了生存背叛朋友、为了大局放弃原则 |
| **后勤代价** | 维持能力/资源需要的持续投入 | 修炼需要大量灵石、机甲需要稀有材料、魔法需要稀有材料 |

**后果链推演法（让世界自己活起来）：**

每条规则都隐含着一条"后果链"，沿着链条深入三层，世界就开始自己构建自己了：

```
规则 → 经济 → 政治 → 日常生活
```

**例子**：设定一条规则——"治愈魔法存在，但只有极少数人天生能使用"

- 第一层（经济）：治愈师极其稀缺，治疗费用天价→普通人看不起病→黑市出现假冒治愈师→治愈师成为各方势力争夺的资源
- 第二层（政治）：皇室垄断治愈师→反对势力试图抢夺/培养治愈师→治愈师成为政治筹码→治愈师本人没有自由
- 第三层（日常生活）：普通人受伤只能硬扛或找偏方→人们对治愈师既崇拜又怨恨→出现"反治愈师"极端组织→主角如果是治愈师，他的每一步都在这个链条中

**关键原则**：
- 代价必须是"持续的"，不是一次性的——每次使用都要付出
- 代价必须是"有意义的"，不是形式上的——代价要能影响人物的选择
- 长期后果必须"带回"——至少在后面的剧情中再出现一次，提醒读者这个代价的存在
- 没有代价的能力会毁掉剧情张力——如果主角可以无限使用能力，就没有紧张感了

#### 第三招：分层释放——不要一次性倒给读者

**核心思路**：新手最容易犯的错是"设定大段倾倒"（lore dump）——第一章就把世界观所有设定全说出来。正确的做法是分层释放，让读者在剧情中自然了解世界。

**三层设定释放法：**

| 层级 | 内容 | 处理方式 | 占比 |
|------|------|---------|------|
| **核心设定** | 直接影响当前情节的规则和事实 | 必须写进小说，通过剧情和人物行动展现 | 30% |
| **背景设定** | 支持核心设定的逻辑基础 | 作者心里有数，但不要全部写出来，需要时才释放 | 50% |
| **风味设定** | 给世界特色的细节（民俗/小吃/服饰/节日） | 偶尔投放一两个，增加真实感和沉浸感 | 20% |

**释放技巧：**

1. **通过人物行动展现，不要旁白说明**
   - 错误："这个世界的修炼分为炼气、筑基、金丹三个等级，炼气期有九层..."
   - 正确："他运转功法，灵气在经脉中运转了九个周天，终于冲破了炼气九层的瓶颈。隔壁传来一声冷哼：'又一个炼气期的废物，也敢住内门？'"

2. **通过冲突和代价展现规则**
   - 让人物因为"不懂规则"而付出代价，读者自然就理解了规则
   - 例子：主角不知道"夜间不能使用魔法"，用了之后被魔法警察追捕，读者就知道了这条规则

3. **通过对话自然透露**
   - 角色之间的闲聊、争吵、谈判中自然带出设定
   - 不要让角色说"众所周知，这个世界..."——真实的人不会这样说话

4. **设定释放的节奏**
   - 第一章：只释放理解当前剧情必需的设定（1-2条核心规则）
   - 前三章：逐步释放主角所处环境的设定
   - 第一卷：释放主要势力和力量体系的设定
   - 后续：随着主角探索新区域，释放新的设定
   - **永远不要一次性释放超过3条新设定**——读者记不住

5. **"冰山原则"**
   - 露出水面的是剧情需要的设定（10%）
   - 水下的是作者心里有数但没写出来的设定（90%）
   - 读者感受到的是"这个世界很真实、很完整"，但不会被设定淹没

### 三、世界观设计七层模型

**第一层：核心规则（世界的"物理定律"）**——最底层，决定世界运行方式。
要回答：最独特的规则是什么？力量来源（灵气/科技/血脉/系统/信仰）？等级体系（多少级、每级差距、顶级状态）？限制和代价（使用条件/消耗/副作用/禁忌）？绝对不能做的事（违反会怎样）？
```
核心规则名称：　规则描述（一句话）：
力量来源：
等级体系（从低到高）：1级[名称-能力范围-稀有度] ... 顶级[名称-全世界多少人达到]
使用代价/限制：
规则禁忌（绝对不能违反的）：
```

**第二层：地理与空间**——地理格局（大陆/星球/多维）；主要区域的特征、气候、资源；交通方式和时间成本；禁区/秘境的特殊规则；故事主要发生在哪、区域间的空间关系。

**第三层：种族与生物**——智慧种族及特征/能力/寿命/文化；种族关系（共存/对立/联盟）；已灭绝或传说种族留下了什么；重要非智慧生物的等级习性。单一种族世界观可简化为"不同群体/阶层"。

**第四层：社会与文明**——社会制度（封建/帝国/宗门/联邦）；阶层结构与流动通道；经济体系（货币/产业/资源分配）；法律秩序；知识传承方式；主流价值观。
```
主要势力列表：[势力名] 制度/核心区域/实力排名/掌权者/内部矛盾/与主角关系
阶层结构：顶层-中层-底层 + 流动通道
经济体系：货币及购买力 / 主要产业 / 资源分布
文化与价值观：主流信仰 / 重要节日仪式 / 禁忌习俗
```

**第五层：历史与传说**——创世纪（真实的或传说的）；重大事件（大战争/灾难/变革）及对现在的影响（遗留仇恨/未解谜团/传承宝物）；传说中的人/物/事是真是假、与主线什么关系；**历史的"真相"和"流传版本"的差异本身就是剧情**。历史不是背景板，是剧情的矿藏。

**第六层：神秘与未知**——连顶级强者都不知道的未解之谜；"世界之外"的存在（神/高维生命/系统创造者）；核心规则的本质（可以不揭示，但作者心里要有确定答案）；预言/宿命是真的还是可打破的。**神秘≠含糊**——随时打补丁的"神秘"会让读者觉得不靠谱。

**第七层：日常与生活**——普通人的一天（吃穿住做什么）；物价（一顿饭/一间房/一把武器多少钱）；娱乐方式；医疗寿命；信息传递方式。不必全写出，但作者要心里有数——偶尔露一两个细节（"一碗面三个铜板"），真实感立刻上来。

### 四、世界观与剧情的结合技法

1. **设定释放节奏**：不在第一章倒出全部世界观；按"剧情需要"释放（主角遇到什么就解释什么）；通过人物的使用/对话/反应展现，不旁白大段介绍；重要设定可"先展示后解释"。
2. **世界观制造冲突**：规则冲突（科技vs修仙）、资源冲突（稀缺资源争夺）、阶层冲突、种族冲突、历史冲突（过去的恩怨延续到现在）、禁忌冲突（有人要打破规则有人要维护）——好的世界观本身就能产生剧情。
3. **世界观的"反转"用法**：前期认知后期可推翻（"原来这个世界的规则是假的"）；传说英雄可能是坏人；世界真相与主角核心目标相关。反转必须有伏笔，不能突然掀桌子。

### 五、世界观自检

1. 核心规则能用三句话说清？自洽无矛盾、不用随时打补丁？
2. 能力有代价？会不会强到剧情没张力？
3. 把故事换到现实世界还成立吗？（成立=结合不够）
4. 释放可控？会不会第一章信息过载？
5. 有没有设计了但完全用不到的设定？（有就删或留续集）
6. 普通人怎么生活？有"活人感"吗？
7. 写长了能支撑更多剧情？有足够的"未知区域"？

## 第二部分：技能/金手指设计

### 一、核心原则

1. **能力是剧情的工具**：设计技能先想"会给主角制造什么麻烦、带来什么选择、推动什么剧情"。能力的限制=剧情的冲突来源。
2. **没有代价的能力会毁掉故事**：代价可以是消耗资源（灵力/体力/寿命）、使用条件（特定时间/姿势/情绪）、副作用（反噬/失控/冷却）、道德代价。能力越强代价越重。
3. **能力要有成长曲线**：不能一开始满级；成长方式：修炼升级/领悟新用法/组合能力/突破限制/付出代价解锁新形态；每次提升后必须面对匹配新等级的挑战。
4. **能力体系要有层次感**：明确的强弱层级；能力之间有克制关系（不是纯数值碾压）；弱者可通过战术/智慧/特殊能力克制强者——这是战斗爽感的来源。

### 二、金手指设计

**常见类型**：

| 类型 | 核心机制 | 设计要点 |
|------|---------|---------|
| 系统流 | 任务/奖励/商城/面板 | 规则清晰，任务有挑战性，不能什么都给 |
| 穿越/重生 | 前世记忆/知识 | 信息差是优势但不能全知全能，要有变量 |
| 特殊体质/血脉 | 天生特殊能力 | 觉醒有触发条件，能力阶段性解锁 |
| 随身空间/法宝 | 独立空间/道具 | 功能有限制，不能变万能仓库+时间加速器 |
| 知识穿越 | 现代知识到古代/异界 | 知识要落地有专业限制，不能什么都懂 |
| 召唤/契约 | 召唤强大存在 | 召唤物有自己的意志和限制 |
| 复制/掠夺 | 复制他人能力 | 有条件限制，不能无限复制最强能力 |
| 模拟器/推演 | 模拟未来 | 结果不能100%准确，要有变量和代价 |

**金手指五问**：①核心规则是什么（一句话）？②限制和代价？③成长方式？④会给主角制造什么麻烦（金手指也是麻烦来源）？⑤和主线的关系（来源/终极秘密是否关联核心冲突）？

**金手指的"度"**：太弱没存在感；太强剧情没张力。合适的度：在特定领域有优势，但发挥需要条件、代价、智慧。**金手指解决一个问题的同时，应该制造两个新问题**。

**金手指的"秘密"**：好的金手指本身有故事（从哪来？为什么选主角？终极功能？），可成主线线索；功能逐步解锁，每次解锁都是小高潮；可以有"自我意识"或"隐藏目的"。

### 三、技能/功法体系设计

**等级体系**：确定大小等级数量；名称符合世界观风格（修仙：炼气→筑基→金丹；都市：F→S）；等级间差距明确（完全打不过还是有胜算）；顶级状态描述清楚（多少人达到、什么特权）。
```
等级名称：
达到条件：（资源/领悟/考验）
能力范围：（这个等级能做到什么）
寿命变化（如有）：
社会地位：
数量稀有度：
突破瓶颈：（从下一级升上来最难的是什么）
```

**技能分类**：按功能（攻击/防御/辅助/控制/移动/感知/特殊）；按稀有度（普通→传说→禁忌）。

**技能设计卡**：
```
技能名称：　所属体系：　等级/品阶：　类型：
学习条件：　核心效果：（一句话）
详细效果：强度 / 作用范围 / 持续时间 / 冷却时间
消耗：（灵力/体力/精神力/寿命）
使用条件/限制：　副作用/反噬：
克制关系：（被什么克制/克制什么）
升级路线：　独特性：
在剧情中的功能：（解决什么问题/制造什么麻烦）
```

**技能组合与进阶**：可组合的技能（组合出新效果=以弱胜强的重要手段）；基础技能可进阶且有分支选择；主角可自创技能（体现智慧和独特性）；不同体系可融合。

### 四、能力平衡设计

1. **强弱梯度**：等级差距不是绝对碾压——低等级对高等级应有"理论上的胜算"（战术/环境/特殊能力）；越级战斗有明确代价和条件。
2. **能力克制**：属性克制（火克木）、机制克制（速度克力量）、规则克制——主角利用克制以弱胜强是战斗爽感核心。
3. **主角能力的"天花板"**：当前阶段有明确天花板（等级上限/金手指限制/世界规则限制），让成长有目标感，防能力膨胀失控；天花板被打破时应是重要剧情节点。
4. **避免能力膨胀**：不每几章加新能力（读者记不住，旧能力失去存在感）；新能力要有仪式感和代价；旧能力持续使用升级；定期清理能力体系（合并相似/淘汰过时/强化核心）。

## 第三部分：战斗体系设计

### 一、核心原则

1. **战斗是剧情的高潮，不是数值比拼**：胜负由战术、智慧、意志、环境、克制关系共同决定；每场战斗有故事性——起伏、转折、意外、情感。
2. **战斗规则清晰且一致**：读者需要知道"这个世界的战斗怎么打"才能代入；规则一旦确立全书遵守；战斗中的"意外"应是规则内的意外（利用规则漏洞/组合），不是规则外开挂。
3. **战斗要有信息量**：人物信息（性格/智慧/底线）、设定信息（能力规则）、剧情信息（伏笔/关系变化）。打完什么信息都没传递=无效战斗。
4. **节奏要有呼吸感**：打打停停、快慢交替；停顿（对话/观察/心理）给读者喘息；高潮前蓄力，高潮后余韵。

### 二、战斗规则体系

**底层逻辑**：战斗的本质（力量比拼/技巧较量/意志对决/规则博弈/资源消耗）；决定胜负的因素（等级/技能/战术/装备/环境/意志/运气）；绝对不能违反的战斗规则；终止条件（死亡/认输/失去战斗能力/裁判终止）。

**胜负因素权重**：等级实力40% | 技能20% | 战术智慧15% | 装备10% | 环境5% | 意志5% | 运气<5%。

**资源系统**：生命/体力（恢复有代价和时间）、能量（总量有限不能无限放技能）、技能冷却、装备耐久、状态debuff、信息情报（知己知彼，信息差制造以弱胜强）。

**空间规则**：地形/障碍物/高低差/边界的影响；规则区域（能力增强/减弱/失效）；战斗能否移动；有无旁观者。

**社会规则**：世界怎么看待战斗（崇尚武力/禁止私斗/竞技场）；战斗规矩（不偷袭/不用毒/点到为止）；违反规矩的后果；正式战斗（决斗/比武/战争）和私下战斗（暗杀）规则不同。

### 三、战斗类型

**按规模**：单挑（个人能力+心理描写）| 小队战（配合和分工）| 群战（整体局势+关键人物，广角+聚焦）| 战争（战略战术，主角是"关键点"非全战场）| BOSS战（压迫感+团队配合+明确阶段）。

**按目的**：生死战（张力最大，有绝望感）| 比试（技巧展示，有留手）| 竞技（规则裁判+观赏性+观众）| 暗杀（信息差+隐蔽+一击定胜负）| 保卫战（不能退的理由+牺牲）| 突围（移动+方向选择+且战且退）| 复仇战（情绪浓度高+积压爆发）。

**按风格**：硬核战术流（策略/信息差/资源管理，像下棋）| 热血燃向（意志/信念/爆发）| 智商碾压流（开战前已定胜负）| 暴力美学流（画面感优先）| 规则博弈流（谁更懂规则谁赢）。

### 四、战斗节奏设计

**单场战斗五段结构**：
```
【开局】试探（10-20%）：互相观察展示基础能力，建立强弱认知，可对话（放狠话/试探/心理战）
【发展】攻防拉锯（30-40%）：认真起来，有来有回，展示战术和技能组合，可有意外（环境/第三方/隐藏能力）
【转折】局势变化（15-20%）：底牌/失误/环境变化，均势变一方占优，被压制方进入困境
【高潮】最终爆发（15-20%）：最后一搏或终结一击，最强技能+最燃台词+最关键选择
【余韵】战后（5-10%）：结果和各方反应，伤势/关系变化/新危机
```

**呼吸点**：开局后第一次交手后插入观察/心理/对话；每2-3个攻防回合插入停顿（对峙/环境变化）；转折前插慢镜头（时间仿佛静止/内心独白/细节特写）；高潮最强一击后插入寂静（所有人愣住）。

**快慢节奏**：快——短句短段动作动词，用于攻击闪避爆发；慢——长句细节心理，用于关键瞬间/转折前/高潮蓄力；快慢交替像呼吸（一直快读者累，一直慢读者困）；最关键一击用慢镜头详写。

### 五、战斗写作技法

1. **动作描写**：具体不模糊（"右脚蹬地，身体右转，右拳带着风声砸向对方面门"）；有因果链（因为对方攻A所以闪B反击C）；有身体感（肌肉紧绷/呼吸/疼痛位置）；有空间感（位置关系/距离/移动方向）。
2. **技能展示**：首次使用要"隆重"（蓄力/视觉/声音/威力/旁观者反应）；后续使用"简洁"（简称或一句带过）；每个技能有独特视觉标识；旧技能组合出新效果比新技能更有爽感。
3. **心理描写**：战斗中想的是"决策"不是"抒情"（他下一步攻哪/我用什么反击/体力还剩多少）；心理活动短句片段式；关键决策可放慢详写权衡；高手用"直觉"（"他没有思考，身体已经动了"）。
4. **旁观者反应**：爽感放大器；分层（普通人"好厉害"→内行"这技巧不简单"→强者"他居然达到了这个境界"）；用认知差制造爽感（以为主角输结果翻盘）；旁观者是调料不抢戏。
5. **战斗对话**：短句/口号/挑衅，不长篇大论；有功能（心理战/情报战/情感爆发）；最燃台词留到高潮；沉默也是表达。

### 六、战斗设计自检

1. 这场战斗有明确目的和功能吗？
2. 胜负合理吗（实力/战术/智慧，无"强行赢"）？
3. 有起伏吗（攻防转换/局势变化，不是一边倒）？
4. 能力使用与设定一致吗（无突然冒出的新能力）？
5. 节奏有呼吸感吗？
6. 有信息增量吗（打完读者获得了什么）？
7. 情感有落点吗？
8. 战后有影响吗（伤势/关系/局势/新危机）？
