## 第一部分：番茄特色品类技法

### 一、脑洞文

**核心**：新奇设定+强冲突+快节奏，"开局即高潮"。

**三要素**：
1. **核心设定新奇**：一句话说出来别人会说"有点意思"（"我能看到别人的死亡倒计时""我的影子有自己的意识"）；差的脑洞："我有一个系统"（普通）、"我穿越了"（老套）。
2. **节奏极快**：开篇300字必须抛出核心脑洞；每3章一个小反转，每10章一个大反转；不能有超过2章的过渡章。
3. **反转密集**：读者以为A结果B；配角以为废物结果大佬；看似巧合结果布局。反转必须在设定内自洽。

**技巧**：开篇即高潮不铺垫；设定分层释放（核心第一章抛出，细节和限制后面逐步给，保持新鲜感）；利用信息差；配角反应是爽感关键（震惊/不解/恐惧/崇拜）；定期升级设定（"看到死亡倒计时"→"能改变死亡时间"→"看到自己的"）。

**避坑**：设定太复杂（看不懂就弃书，一句话能说清最好）；节奏太慢（前3章没抓住就完了）；反转太牵强（要有伏笔不机械降神）；只有脑洞没有故事（设定是壳故事是核）；设定膨胀（后期加维度可以，不能无所不能）。

### 二、衍生文/同人文

**核心**：借用已有IP的世界观和角色二次创作，自带流量（原作粉丝主动搜索；代入快不需从零介绍；有话题性）。

**类型**：动漫衍生、游戏衍生、影视衍生、小说衍生、历史/公版衍生（三国/水浒/西游记）。

**技巧**：
- **尊重原作设定**：世界观、角色性格、能力体系不随意修改。
- **角色不OOC**：行为必须符合原作性格，不能让高冷角色变话痨——**这是衍生文最大的雷区**。
- **在原作基础上创新**：插入原创主角、改变关键事件、探索原作未展开的支线、穿越到原作世界；不能照搬原作剧情（读者看过原作了）。
- **抓住原作的"意难平"**：读者遗憾的地方（角色死亡、CP没在一起）是最好的切入点。
- **平衡粉丝和新读者**：既让粉丝满意（有彩蛋有还原），也让新读者能看懂（必要设定介绍）。
- **版权**：建议选平台已授权IP或公版IP。

**避坑**：照搬原作；角色OOC；原创主角碾压原作角色（粉丝反感）；只有原创主角演戏忽略原作角色；碰未授权商用红线。

### 三、癫文

**核心**：反套路、情绪直接、主角"不正常"（代表作《癫，都癫，癫点好啊》）。

**三特征**：
1. **主角不按常理出牌**：正常人遇危险会跑，癫文主角迎上去；被欺负当场发疯。"癫"不是傻，是看透规则后的"不按规则玩"。
2. **情绪表达直接**：不高兴就骂，不爽就打，喜欢就追，没有"内心挣扎三百回合"。但"直接"≠"无脑"——行为有自己的逻辑。
3. **节奏快、爽点密、黑色幽默**：几乎每章都有爽点；用荒诞方式讲严肃的事；反套路彻底（读者以为A，结果B，且B更离谱）。

**技巧**：给"癫"一个合理原因（被逼的/天生的/看透世界的）；癫的行为有内在逻辑（不是随机发疯）；用配角的正常衬托主角的癫；**癫但不恶**（有自己的底线和善良）；金句频出（疯言疯语但有道理，是传播点）。

**避坑**：为癫而癫（无原因无逻辑）；主角太恶（癫可以疯不能坏）；逻辑崩坏（荒诞但核心要自洽）；只有癫没有故事（癫是风格故事是核）；模仿痕迹重（癫的魅力在独特）。

### 四、番茄特色品类通用提醒

不要盲目跟风（选自己擅长的比选最火的重要）；不要忽视平台规则（审核/更新/字数）；不要只写开头不看长线（脑洞文/癫文开头易出彩，长线才是收入关键）；不要忽略数据反馈（算法基于数据，按数据调整方向）。

## 第二部分：官场职场文技法

> 官场、职场、商战、权力博弈、体制生存。核心驱动为**权力感与智力博弈**。

### 一、五大铁律

1. **信息即权力律**：博弈本质是信息博弈——每场对话都是情报交换，每份文件都是筹码；主角的成长=信息网的扩张。
2. **言外之意律**：核心魅力在"潜台词"——角色说的话不代表他真正想说的；读者享受"读懂言外之意"的智力快感。
3. **规则内博弈律**：在既有规则内靠智慧、耐心和人际关系实现目标；不靠拳头靠脑子；利用规则、解释规则、钻规则空子，不随意打破规则。
4. **立场 > 善恶律**：没有纯粹的好人坏人，只有不同立场的人；每个人的行为从自己立场看都是"合理的"；反派也有逻辑和苦衷。
5. **累积制胜律**：胜利由无数微小优势累积（一个情报、一次好感、一次站队正确、一次关键投票）；崛起是渐进的，不一步登天。

### 二、读者预期模型

| 读者要的 | 读者不要的 |
|---------|-----------|
| 精彩的权力博弈/办公室政治 | 简单粗暴的以暴制暴 |
| 有深度的潜台词对话 | 直白无味的对话 |
| 真实的体制内运作逻辑 | 外行想当然的官场描写 |
| 主角的智力/情商成长 | 靠运气/金手指升迁 |
| 复杂立体的对手 | 脸谱化的贪官坏人 |
| 道德灰色地带的挣扎 | 非黑即白的道德判断 |
| 层层递进的权力升级感 | 一步登天 |

**题材公式**：官场职场爽感 = (博弈层数 × 信息差精彩度 × 人际网络复杂度) ÷ 降智操作数 × 真实感系数。一个事件至少要有2-3层博弈（表层+中层+深层）。

### 三、写作技巧

1. **对话即博弈**：60-70%叙事靠对话推进（电话/会议/私下谈话）；每段对话有潜台词（说A实际是B）；停顿、语气、用词都是博弈的一部分；会议里谁先发言、谁附和、谁沉默、谁反对都是权力关系的体现。
2. **信息差叙事**：读者比角色多（读者着急"快发现啊"）；角色比读者多（奇怪行为后面才解释）；不同角色掌握不同信息；关键信息的揭示时机很重要。
3. **站队与博弈**：核心是"站队"——站错队比能力差更致命；多方势力中周旋；每次站队都有代价和收益，没有完美选择；今天的盟友可能是明天的敌人。
4. **节奏控制**：一个"局"（完整博弈）5-10章：布局（慢，让读者看到各方算计）→ 下套 → 收网（快，集中爆发）→ 余波（后果影响后续）。不能一直布局不收网。
5. **真实感营造**：体制内术语、流程、等级关系准确；办公室政治细节（谁坐什么位置、谁先敬酒、谁的办公室大）；文件流转、审批流程、会议规矩；不懂就查资料，不想当然。

### 四、避坑

主角光环太重（不能每次都赢）；反派降智（对手失败是因为信息差或判断失误，不是蠢）；金手指太逆天（官场金手指应是"信息优势"或"经验优势"不是超能力）；感情线喧宾夺主；布局太久不收网；道德说教（魅力在灰色地带，主角不是圣人）；违反常识（外行一眼看穿的错误会劝退懂行读者）。

## 自检清单

**脑洞文**：设定一句话说得清且"有点意思"？开篇300字抛设定？每3章小反转每10章大反转？反转有伏笔？设定分层释放无崩坏？
**衍生同人**：尊重原作设定？角色不OOC？有原创剧情？抓住意难平？平衡粉丝和新读者？版权安全？
**癫文**："癫"有合理原因？行为有内在逻辑？配角正常衬托主角癫？癫但不恶？反套路彻底？有金句？
**官场职场**：五大铁律遵守？对话有潜台词？每事件2-3层博弈？对手智商在线？崛起渐进？体制逻辑真实？有灰色挣扎？每个"局"完整（布局→下套→收网→余波）？信息差利用好？主角有失败挫折？
