# 快速启动与模板库：拿到就能用的网文创作工具箱

> "入口层"：不知道从哪开始、需要可直接复制的模板、遇到问题快速定位时，先读本文档。
> **核心地位**：`06a`（故事感十二支柱）和 `06b`（AI通病诊断）是全包方法论核心。使用任何模板前先读 `06a`——故事感是"1"，其他技法都是"0"；每个创作阶段都对照 `06b` 自检。

## 目录

- 一、从零开始写小说：7步SOP

## 一、从零开始写小说：7步SOP

按顺序推进，每步用"检查点"确认后再进入下一步。

### 第1步：核心定位（30分钟）
填写"核心定位五问模板"（模板1）。
**检查点**：一句话讲清这本书（"一个___的人，在___的世界里，想要___，但___阻止了他"）；主角欲望具体可操作；核心冲突清晰；爽点/卖点明确；平台和读者画像清晰。
卡住了 → `01-foundations.md` 核心定位五问。

### 第2步：世界观与人设（1-2天）
填世界观速建模板（模板3，先写核心规则和关键设定）→ 填主角人物卡（模板2，重点：欲望/恐惧/矛盾性/弧光）→ 填2-3个核心配角卡（重点：与主角的关系、各自目标）→ 画简单人物关系图。
**检查点**：核心规则≤3条且每条有代价；主角欲望与世界观核心矛盾相关（换个世界观故事就不成立）；主角有外在目标和内在成长；每个配角有自己的目标；主角和至少一个配角有"不可调和的矛盾"或"深度羁绊"。
卡住了 → 世界观 `03` / 人设 `04`。

### 第3步：全书大纲与剧情结构（2-3天）
填卷级大纲模板（模板4，先规划3-5卷）→ 规划主线阶段划分 → 列3-5条重要支线（明确功能和与主线交织点）→ 列5-10个重要伏笔（标注埋设和回收位置，用伏笔追踪表）。
**检查点**：三句话说清全书弧线；每卷有核心冲突和卷末高潮，卷间有升级感；主线节奏合理（15%开局+65%发展+20%高潮结局）；每条支线有存在的理由；重要伏笔有回收计划且埋收间隔≤50章。
卡住了 → 大纲 `01` / 剧情结构伏笔 `05` / 战斗体系 `03`。

### 第4步：开篇三章（1-2天）
先写前三章细纲（模板5）→ 写第一章（前300字切入事件，不大段背景介绍）→ 第二章（展示主角性格能力，引入第一个冲突）→ 第三章（第一个小高潮，章末强钩子）→ 用开篇自检清单检查。
**开篇自检**：前300字有事件/冲突/钩子（不是"某某大陆某某年间"）；前三章主角核心性格已通过行动展示；核心冲突已浮现；每章结尾有钩子；世界观通过行动对话自然展示；无"属性面板式"人物出场。
卡住了 → 开篇 `02` 第三部分 / 细纲 `01` / 故事感 `06a`+`06b`。

### 第5步：稳定更新（持续）
每章写正文前先写细纲（10分钟）→ 按细纲一气呵成不边写边改 → 写完做单章自检 → 每卷做完做卷级复盘。
**单章自检**：有明确功能不是水文；有冲突（连续3章无冲突即水文）；章末有钩子；视角稳定；无情绪标签；节奏有快慢变化；无AI腔词句（"与此同时""值得一提的是""非常"）。
卡住了 → 卡文 `02` 第一部分四 / 日常场景 `05`。

### 第6步：文风打磨（持续/阶段性）
每5-10章做一次文风自检：无AI塑料味（对照 `06b` 特征表）；有故事感（对照 `06a` 十二支柱）；人物说话有个性；叙事声音统一；节奏有呼吸感。统一全书文风先定"主文风+辅助技法"。
卡住了 → 去AI味/故事感/名家文风 `06a`+`06b` / 搞笑/迪化/智斗 `07a`。

### 第7步：审核质检（每章/每卷）
每章：单章审核（合规+逻辑+体验）；每卷：卷级审核（主线推进+人物弧光+伏笔回收+节奏）。审核体系见 `02` 第二部分，维护文档体系见 `12`。

## 二、可直接复制的模板

### 模板1：核心定位五问

```
【书名】（暂定）
【一句话故事】一个______的人，在______的世界里，想要______，但______阻止了他。

1. 主角是谁？（身份/性格/核心特质，一句话）
2. 主角想要什么？（外在目标，具体可操作，不是"变强"）
3. 主角真正需要什么？（内在成长/情感需求，可能主角自己都没意识到）
4. 谁/什么阻止了他？（核心冲突，反派/环境/内心，不可调和的矛盾是什么）
5. 读者为什么要追这本书？（核心爽点/卖点/情绪价值，一句话）

【目标平台】番茄/起点/晋江/其他：
【目标读者】男频/女频，年龄层，偏好：
【预计字数】万字：
【文风方向】（轻松搞笑/冷峻智斗/热血燃向/细腻情感）
```

### 模板2：人物卡（主角/核心配角通用）

```
【姓名】【年龄】【身份】（表面身份/真实身份）
【一句话人设】

▌外在
- 外貌特征：（2-3个有记忆点，不是"英俊潇洒"）
- 穿着/打扮：
- 习惯性动作/口头禅：（增加活人感）
- 声音/说话方式：（语速/用词/语气）

▌内在
- 核心性格：（2-3个关键词，要有矛盾性，如"外表冷漠内心柔软"）
- 现在想要什么：（具体的、可操作的外在目标）
- 真正需要什么：（内在的情感需求/成长方向）
- 为什么想要这个：（过去的经历造成的执念/动机）
- 愿意为此付出什么代价：（衡量欲望强度）
- 最大的恐惧：
- 道德底线：（什么事绝对不做，什么情况下会突破底线）

▌背景
- 出身/家庭：
- 关键经历：（2-3件塑造了这个人的过去事件）
- 秘密：

▌人物弧光
- 开始状态 → 转折点（什么事件/人让他开始改变）→ 结束状态
- 弧光类型：正向成长/负向堕落/平坦（有经历但本质不变）

▌关系
- 和主角的关系：（如果是配角）
- 重要关系人：（2-3个，写明关系性质和矛盾/羁绊）
- 对其他人的态度：

▌活人感细节（至少填3个）
- 生活习惯/小癖好：（如"紧张时摸左耳""吃饭先把葱挑出来"）
- 不完美的地方：（如"路痴""嘴硬心软"）
- 无关紧要的小事：（如"喜欢下雨天""唱歌跑调但自己不知道"）
```

### 模板3：世界观速建模板

```
【世界观名称】
【一句话设定】（这个世界最核心的、和其他世界不一样的设定）

▌核心规则（不超过3条，每条必须有代价/限制）
1. 规则：　代价/限制：
2. 规则：　代价/限制：
3. 规则：　代价/限制：

▌力量/能力体系（如适用）
- 力量来源：
- 等级划分：（从低到高，不超过7级）
- 获得方式：
- 能力限制/代价：
- 金手指/特殊能力：（主角的，说明来源和限制）

▌地理与势力
- 主要地理区域：（2-3个，每个一句话）
- 主要势力：（3-5个，每个：名称/核心诉求/和主角的关系）
- 势力间关系：（敌对/结盟/中立）

▌社会与文化
- 社会结构 / 经济货币 / 重要习俗禁忌 / 主流价值观

▌历史与传说
- 世界起源/关键历史事件：（1-2个，影响当前格局）
- 重要传说/预言：（可能和主线相关）
- 当前时代背景：

▌日常生活（增加真实感，至少填3个）
- 普通人吃什么/穿什么/住什么 / 交通方式 / 娱乐社交
- 一个有生活气息的细节：（如"城里的早市从寅时开始，卖豆浆的老张头总是多给常客半勺"）

▌世界观与主角的关系
- 核心矛盾如何和主角的追求相关？
- 换个世界观这个故事还成立吗？（成立=结合不够紧）
```

### 模板4：卷级大纲模板

```
【全书总览】
- 预计总卷数 / 总字数
- 全书核心弧线：（开头状态→中间经历→结尾状态，三句话）

▌第___卷：《卷名》
- 字数：约___万字（___章）
- 本卷核心冲突 / 主角目标（可交付的中间目标）
- 本卷功能：（开局/发展/升级/转折/高潮/结局）
- 时间跨度 / 主要场景

【关键节点】
1. 卷首：（怎么开场，引入什么新元素）
2. 第一个转折点：
3. 卷中高潮：
4. 第二个转折点：
5. 卷末高潮：（本卷最高潮）
6. 卷末钩子：（留什么悬念让读者想看下一卷）

【本卷重要伏笔】
- 伏笔1：内容___，埋于第___章，计划回收第___卷第___章

【本卷人物变化】
- 主角 / 重要配角：（谁登场/离开/重大变化）

【本卷爽点规划】
- 小爽点（每3-5章一个）2-3个 / 大爽点（每10-15章一个）1-2个 / 卷末终极爽点
```

### 模板5：章节细纲模板

```
【第___章：章名】
- 本章字数：约___字
- 本章功能：推进主线/塑造人物/铺垫伏笔/高潮/过渡/日常
- 视角人物：
- 场景：（在哪里，什么时间）

【情节推进】（按顺序，每步1-2句话）
1. 开场：（怎么开始，承接上一章什么钩子）
2. 发展：
3. 冲突：（本章核心冲突/张力点）
4. 转折：（意外/反转/新信息）
5. 结尾：（章末钩子具体写出来）

【信息释放】
- 本章释放的新信息 / 暗示但不说明的信息（伏笔悬念）/ 回收的旧伏笔

【人物塑造】
- 本章重点塑造谁 / 通过什么事件对话展示 / 关系变化

【爽点/钩子】
- 本章爽点：（打脸/反转/升级/揭秘/情感冲击）
- 章末钩子：（具体写出）

【节奏规划】
- 开头/中间/结尾节奏：快/中/慢
- 关键情绪点：（哪里用极短句/独立成段制造冲击力）

【写作提醒】（本章特别注意的，如"战斗场景用短句""这里要展示而非告知"）
```

### 模板6：场景卡（重要场景用）

```
【场景名称】
- 所在章节 / 场景类型（战斗/对话/悬疑/情感/大场面/日常）/ 叙事功能

▌空间布局
- 具体地点 / 空间结构（区域/物品/出入口）
- 场景独特标识：（什么让这个场景有记忆点）

▌氛围与感官
- 整体氛围：（3-5个词）
- 视觉（首先看到什么）/ 听觉 / 嗅觉 / 触觉 / 味觉（如适用）

▌人物与互动
- 在场人物 / 位置关系（谁面对谁、谁站谁坐）
- 核心互动 / 关系变化

▌时间动态
- 持续时间 / 环境变化 / 节奏变化点

▌叙事功能实现
- 推进了什么剧情 / 塑造了什么人物 / 释放了什么信息
- 埋设/回收了什么伏笔 / 制造了什么爽点/情感冲击

▌写作提醒
- 记忆点 / 最有冲击力的瞬间 / 避免的问题
```

## 四、使用建议

1. **第一次使用**：从7步SOP开始按顺序推进；遇到问题先查诊断表再深入对应文档。
2. **日常写作**：写正文前用模板5规划，写完用单章自检检查。
3. **按需读取**：references/ 下共 16 个文档，不要一次全读。全局地图、权威源、数值口径见 `SKILL.md`。
4. **模板是起点不是枷锁**：写熟后可按自己习惯调整。
5. **设定类文档单独建档**（世界观/人设/技能/伏笔表），写正文时随时查阅——长篇必按 `12` 建维护文档体系。
