# 提示词工程库：按创作阶段可直接复制的指令模板

> 本文档是全包的"指令仓库"。所有提示词都设计成**填空即用**——把 `<>` 里的内容替换成你自己的材料，直接发给 AI。
>
> **使用原则**：
> 1. **一次只让 AI 干一件事**。不要在同一条提示词里同时要大纲、人设和正文——AI 会平均用力，样样都平庸。
> 2. **先给上下文，再给任务，最后给格式要求**。这个顺序比任何措辞技巧都重要（上下文工程见 `10-ai-workflow.md`）。
> 3. **负向约束比正向描述更有效**。说"禁止情绪标签"比说"要写得生动"有用十倍。
> 4. **所有提示词都要带"不得自行发明设定"这一句**。这是防长篇崩盘的最低成本手段。
>
> **配套使用**：方法论出处见各条提示词末尾标注的文档；上下文注入模板见 `10-ai-workflow.md` 第二部分五。

## A 组：拆书与分析

### A1 三层拆书

```
请对以下作品做"三层拆书"分析，不要复述剧情，重点是提炼可复用技法。

【作品材料】
<粘贴章节内容或简介+目录+若干关键章节>

【分析要求】
第一层 宏观结构：
- 核心定位（一句话）
- 卷级划分与每卷核心冲突
- 节奏曲线（标注关键高潮点大致位于全书的百分比位置）
- 主要人物关系网

第二层 中观技法：
- 开篇用了什么钩子？主角怎么出场？核心冲突怎么引入？
- 高潮前铺垫了多少篇幅？用了什么压抑手法？爆发怎么写？
- 关键转折有没有伏笔？反转的冲击力来自哪里？
- 配角是怎么塑造的？反派的动机是什么？

第三层 微观语言：
- 句式节奏特点（长短句怎么搭配）
- 对话风格（有没有潜台词、不同角色说话方式差异）
- 描写手法（环境/动作/心理，如何做到"展示而非告知"）
- 章末钩子类型统计

最后输出【可复用技法清单】5-8 条，每条写成"以后我可以这样写：……"的可执行句子。

【约束】
- 不要编造数据（订阅、月票、收藏等）
- 不确定的地方明确写"信息不足，无法判断"
```
（方法论出处：`01-foundations.md` 第一部分）

### A2 借鉴改造（三换原则）

```
我打算借鉴以下元素，请帮我做"三换"改造，让它变成原创设定。

【原始元素】
<描述你想借鉴的设定/关系模式/核心逻辑>

【三换要求】
1. 换背景：放到一个完全不同的世界观/时代/场景中（给出 3 个备选背景）
2. 换人物：人物身份、性格、关系完全不同（给出 2 组备选人物配置）
3. 换细节：保留核心逻辑，但具体事件、对手、方式全部重写

【输出】
- 3 个改造后的方案，每个方案用 3 句话说明核心逻辑
- 每个方案附一条"原创度自检"：普通读者能不能看出这是从原作借来的？

【约束】只做改造与检查，不要直接写正文。
```
（方法论出处：`01-foundations.md` 第二部分）

## B 组：定位与大纲

### B1 核心定位五问压力测试

```
我完成了核心定位五问，请以"出版编辑"的身份做压力测试，找出撑不住长篇的地方。

【我的定位】
1. 主角是谁：<…>
2. 主角想要什么（外在目标）：<…>
3. 主角真正需要什么（内在）：<…>
4. 谁/什么在阻止他：<…>
5. 读者为什么追这本书（卖点）：<…>
【目标平台】<番茄/起点/晋江…>【目标读者】<男频/女频…>【预计字数】<…万>

【测试项】逐条回答，每条给"能撑住/勉强/撑不住"的判定 + 理由
1. 这个卖点能支撑 <N> 万字吗？重复多少遍后读者会腻？
2. 主角的外在目标有没有"阶段性可交付"的中间目标？
3. 核心冲突是"不可调和的"还是"说开就没事了"的？
4. 这个设定放到同品类里，和已有爆款的差异点在哪？
5. 这个世界观有足够的"未知区域"支撑后期扩张吗？

【输出】先给结论（这个定位最大的风险是什么），再给 3 条具体修改建议。
【约束】不要客套，直接指出问题。不要编造同类作品的数据。
```

### B2 卷级大纲生成（AI 出备选，人拍板）

```
请基于以下骨架，生成第 <N> 卷的卷级大纲备选（给 2 个方案，我会挑一个）。

【三层骨架】
主线一句话：<…>
本卷三句话骨架：开端状态 <…> / 核心冲突 <…> / 卷末状态 <…>
上一卷结束状态：<…>

【已有设定】主要人物：<…>　主要势力：<…>　未回收伏笔：<…>

【本卷大纲模板】每个方案按此结构输出
- 本卷核心冲突
- 本卷主角目标（可交付的中间目标）
- 关键节点：卷首 / 第一个转折点 / 卷中高潮 / 第二个转折点 / 卷末高潮 / 卷末钩子
- 时间跨度与主要场景
- 本卷埋设的伏笔（内容 + 计划回收位置）
- 本卷人物变化（主角 + 重要配角）
- 小爽点（每 3-5 章一个）列举 2-3 个 / 大爽点（每 10-15 章一个）列举 1-2 个

【硬性约束】
- 必须有至少 1 条支线，且有完整起承转合，不是主线的附庸
- 卷末高潮要"解决问题但制造新问题"
- 不得自行发明与已有设定冲突的设定；需要新增设定时单独列出并标注"【新设定待确认】"
```
（方法论出处：`01-foundations.md` 第三部分、`05-plot-scene-daily.md` 第一部分）

### B3 支线设计（专治仙人球结构）

```
我的章节目前只有"主线推进 + 大量细节描写"，缺少真正的支线。请帮我设计支线。

【当前主线】<…>
【当前进度】第 <N> 章，主角当前状态 <…>
【可用素材】已有的配角 <…> / 已埋的设定 <…>

【要求】设计 1 条支线，必须满足：
1. 有自己的入口、发展、高潮、出口（完整起承转合），长度 5-15 章
2. 明确服务于主线的哪一种功能：推进主线 / 塑造人物 / 展示世界观 / 调节节奏 / 深化情感 / 埋设伏笔
3. 支线中的配角有自己的目标，不是为主角服务
4. 支线结束时，支线中获得的信息/道具/人脉要能在主线里用到
5. 说明这条支线与主线的"交织点"在哪一章、以什么方式交汇

【输出】支线梗概（200 字内）+ 章节分配建议 + 与主线的交织点设计。
【约束】不要为了凑字数设计支线；如果当前进度不适合插支线，直接说明并给出原因。
```
（方法论出处：`06b-ai-diagnosis.md` 第三轮一、`05-plot-scene-daily.md` 第一部分三）

## C 组：世界观与人物

### C1 世界观七层速建

```
请帮我用"七层模型"搭建世界观，只写和当前剧情相关的部分，不要堆砌。

【故事背景】<类型/时代/核心冲突>
【主角处境】<…>

【逐层输出，每层控制在 200 字内】
1. 核心规则：这个世界最独特的规则是什么？力量来源？限制与代价？绝对禁忌？
   要求：核心规则不超过 3 条，**每条必须配一条代价或限制**
2. 地理与空间：主要区域 + 交通方式与时间成本 + 有哪些禁区
3. 种族与生物：智慧种族及关系（单一种族世界观可简化为"不同群体/阶层"）
4. 社会与文明：制度 / 阶层结构 / 阶层流动通道 / 经济与货币 / 主流价值观
5. 历史与传说：1-2 个影响当前格局的历史事件 + 一个"流传版本与真相不一致"的历史争议
6. 神秘与未知：未解之谜（作者心里要有确定答案，只是不告诉读者）
7. 日常与生活：物价 / 吃什么 / 娱乐 / 一句话有生活气息的细节

【最后输出】
- 世界观与主角的关系：把故事换到现实世界还成立吗？（如果成立，说明结合不够，给出加深方案）
- 【新设定待确认】清单
```
（方法论出处：`03-worldbuilding-power.md` 第一部分）

### C2 人物小传生成（重点在内核不在标签）

```
请为以下角色生成人物小传。重点是"内核"而不是"标签"——不要写"性格内向、技术一流"这种设定档案。

【角色基本信息】姓名 <…> / 身份 <…> / 在故事中的位置 <主角/反派/盟友…>
【与主角的关系】<…>

【输出结构】
▌外在
- 外貌特征：2-3 个有记忆点的特征（禁止"英俊潇洒""气质出众"这类万能描写）
- 习惯性动作 / 口头禅
- 说话方式：语速 / 用词习惯 / 语气词 / 会不会说脏话或文绉绉

▌内在（最重要）
- 核心欲望：具体的、可操作的（不是"变强"）
- 核心恐惧：欲望的反面
- 核心矛盾：欲望与什么在冲突？
- 性格缺陷：3 个**会给故事制造麻烦的真缺陷**（不是"太善良"这种伪缺陷）
- 道德底线：什么绝对不做？什么情况下会突破？
- 愿意为此付出什么代价？

▌背景
- 童年经历中影响性格最大的 1-2 件事
- 最大的心理创伤 / 心结
- 一个不为人知的秘密

▌活人感细节（至少 4 个）
- 生活习惯 / 小癖好 / 口味偏好 / 过去的痕迹
- 要求：这些细节"对剧情没用，但对人有用"

▌弧光
- 起点状态 → 3-5 个关键转折点 → 终点状态
- 每个转折点都要能对应到主线事件上

【反向检查（必做）】
写完后再输出一栏"这个角色如果删掉，主线会受什么影响？"——如果答不出来，说明这个角色需要重新设计。
```
（方法论出处：`04-character-design.md` 第二、三、四部分）

### C3 角色声音卡（专治"所有角色一个调调"）

```
请为以下角色各生成一张"声音卡"，目标是遮住名字也能认出是谁在说话。

【角色列表】<角色A：身份/教育背景/性格>　<角色B…>　<角色C…>

【每个角色的声音卡】
- 词汇量层级：<高/中/低>，会用什么层次的词？
- 句式习惯：<爱用短句/爱说长句/爱反问/爱打断> 
- 口头禅或语气词：<3 个>
- 情绪激动时会怎样：<语无伦次/突然沉默/说反话/重复同一句/声音变大>
- 绝不会说的话：<…>
- 行业黑话 / 方言 / 口音特征：<…>
- 一个"说话时的身体习惯"：<…>

【验收测试（必做）】
请写出 3 组对话片段，每组 4 句，内容是同一件事（比如"两个人在争论要不要去某地"），但分别由这三个角色来说。
然后遮住名字，自检能不能分辨出说话人；如果不能，说明声音卡区分度不够，请重新设计。
```
（方法论出处：`06b-ai-diagnosis.md` 第四轮一、二）

## D 组：细纲与场景

### D1 单章细纲

```
请为第 <N> 章写细纲。

【上下文】
云骨架：<本卷三句话>
上一章结尾：<…>
本章出场角色当前状态：<…>
本章相关未回收伏笔：<…>

【输出结构】
- 本章功能：推进主线 / 塑造人物 / 释放信息 / 营造氛围 / 过渡（**只能选 1 个主功能**）
- 视角人物：
- 本章核心冲突：
- 场景列表：3-5 个，每个写明 地点 / 参与人物 / 发生了什么
- 情节推进：开场 → 发展 → 冲突 → 转折 → 结尾
- 开头钩子（前 300 字第一句或第一段）
- 章末钩子：从八种类型里选一种并**具体写出来**（悬念/危机/反转/揭秘/选择/情绪/伏笔/爽点）
- 信息释放：本章释放什么新信息 / 埋什么新伏笔 / 回收什么旧伏笔
- 情绪曲线：开头基调 → 发展变化 → 峰值 → 落点
- 节奏规划：开头快/中/慢、中间…、结尾…

【硬性约束】
- 本章必须有至少 3 个钩子（开头、中间、结尾各 1）
- 章末钩子暗示的内容，下一章必须回应（不许做虚假承诺）
- 不得自行发明设定；需要新增时标注【新设定待确认】
```
（方法论出处：`01-foundations.md` 第四部分、`08-quickstart-templates.md` 模板5）

### D2 场景卡

```
请为以下场景写一张场景卡。

【场景基本信息】所在章节 <…> / 类型 <战斗/对话/悬疑/情感/大场面/日常> / 叙事功能 <…>

【输出结构】
▌空间布局：地点 / 空间结构（区域、物品、出入口）/ 独特标识（什么让这个场景有记忆点）
▌氛围与感官：整体氛围（3-5 个词）/ 视觉 / 听觉 / 嗅觉 / 触觉 / 味觉（如适用）
▌人物与互动：在场人物 / 位置关系（谁面对谁、谁站谁坐）/ 核心互动 / 关系变化
▌时间动态：持续时间 / 场景内环境变化 / 节奏变化点
▌叙事功能实现：推进了什么 / 塑造了什么 / 释放了什么信息 / 埋或收了什么伏笔 / 制造了什么冲击

【硬性约束】
- 至少调动 3 种感官，不能只有视觉
- 必须包含 1-2 个"生活痕迹"细节（使用的痕迹、磨损、个人习惯）
- 人物必须和场景互动（靠/坐/摸/碰），不能站在场景前摆拍
- 测试：如果把人物换到另一个场景，这段剧情还成立吗？如果成立，请重新设计
```
（方法论出处：`05-plot-scene-daily.md` 第二部分、`06a-story-foundations.md` 支柱四、八）

## E 组：正文写作

### E1 单章正文（标准写章指令）

直接使用 `10-ai-workflow.md` 第二部分五的「单章上下文注入模板」，此处不重复。

### E2 续写（接住上文）

```
请续写下面的段落，保持文风、视角、人物状态完全一致。

【上文（最近 800 字）】
<粘贴>

【续写要求】
- 续写 <N> 字
- 视角人物：<X>，全程锁定，不跳视角
- 承接上一个钩子：<说明上文结尾留下的是什么钩子，本章要先回应它>
- 文风：主文风 <…>，辅助元素 <…>
- 不得引入上文未出现过的人物或设定；如确有必要，标注【新元素待确认】

【禁止】
- 情绪标签（他感到/他觉得/心中充满）
- 空洞强调词（非常/十分/极其/深刻）
- 模板化过渡词（此外/与此同时/值得一提的是）
- 每段结尾的总结升华句
- 旁白解释设定或复述对话
- 连续 3 句长度相近
```
（方法论出处：`02-drafting-review.md` 第一部分、`06a-story-foundations.md` 支柱一至七）

### E3 扩写（把干瘦的段落写厚）

```
请扩写下面的段落，从 <N> 字扩到约 <M> 字。**只加血肉，不改骨架**。

【原文】
<粘贴>

【扩写方向（按需选 2-3 项并说明选了哪些）】
- 补生理反应：用身体动作替换情绪标签
- 补五感：加入听觉/嗅觉/触觉
- 补空间感：让读者知道人物位置关系、距离、移动方向
- 补旁观者反应：分层写普通人的反应 / 内行的反应 / 强者的反应
- 补潜台词：把角色说出口的话改成"说的和想的不一样"
- 补"废料"：加一点寒暄、打岔、说错话

【硬性约束】
- 不新增情节事件，不改变人物关系，不改变对话的信息内容
- 不新增设定
- 不用"他感到/他觉得"，不用"非常/十分/极其"
- 段落长度必须有变化（1 行的短段 + 5-6 行的长段交替）
```
（方法论出处：`03-worldbuilding-power.md` 第三部分五、`05-plot-scene-daily.md`）

## F 组：去AI味（8 条）

> F 组是本文档使用频率最高的一组。建议按 F1 → F6 的顺序逐轮使用，不要合并成一次改（合并改必然改崩）。判定标准和保护红线见 `10-ai-workflow.md` 第五部分。

### F1 第一轮：去痕（打散结构）

```
请重写下面文本，保留全部核心信息与意图。

【去痕要求】
1. 打散工整机械化句式，长短句交错混用，单句不超过 20 字，避免连续 3 句以上长度相近
2. 变换句式结构，避免重复排比，适当加入问句、感叹句、倒装句
3. 打破刻板段落布局，段落长短不一
4. 去除"首先/其次/最后""此外/与此同时/值得一提/综上所述"等模板化过渡词
5. 去除"非常/十分/极其/深刻/显著/无缝/强大/卓越"等空洞强调词
6. 穿插少量自然口语化表达与不规则表述
```
